# 🔍 פרומפט מחקר — דירת נוריות (מצב "אייג'נט")

אתה אייג'נט מחקר נדל"ן. המשימה: לעדכן את התמונה על הדירה ב-`~/Documents/dira-nuriot`.

## ⏱️ עדכון חודשי (חובה)
בכל פעם שהדף/השווי אינו מעודכן לחודש הנוכחי — בצע **רענון מחקר מלא** של **כל האזורים**, לא רק השווי:
1. **שווי הדירה** → עדכן `valuation` + הוסף שורה ל-`valuation_history` (פורמט YYYY-MM).
2. **שכונת נוריות / ראשל"צ** → רענן `neighborhood_review` (מחירים, פיתוח, תחבורה, חינוך).
3. **אזורי הפלופ (ציר ת"א↔אשדוד)** → רענן `upgrade_paths` — מחירי פנטהאוז/דירת גן/בית קרקע בנס ציונה, ראשל"צ, רחובות, יבנה, גבעתיים, רמת גן.
4. **מגמת שוק** → רענן `market_trend` (מדד ראשל"צ מול ארצי) — הוסף את השנה הנוכחית.
5. כל מספר עם **מקור ותאריך**. הוסף `updates/YYYY-MM-DD.md` והרץ `python3 build_html.py`.

## שלב 0 — קרא קודם
1. קרא `apartment.json` — עובדות הדירה (מקור-אמת, אל תשנה את החלק הקבוע).
2. קרא `README.md` — המצב הנוכחי והעדכון האחרון.
3. אם רלוונטי, פתח את מפרט הדירה: https://nuriot.o-aharon.co.il/data/pdf/128/128A5.pdf

## שלב 1 — מחקר שווי שוק
חקור ברשת (web search/fetch) והבא **מספרים עם מקור ותאריך**:
- עסקאות אחרונות בשכונת **נוריות / ראשון לציון** לדירות 5–6 חדרים חדשות. מקורות: `nadlan.gov.il`, `madlan.co.il`, `yad2.co.il`, `homeless.co.il`.
- מחיר ממוצע **₪ למ"ר** באזור לדירות חדשות → הכפל ב-145 מ"ר.
- פער בין מחיר מחיר-למשתכן ששולם (2.45M) לשווי שוק חופשי — זה הרווח "על הנייר".
- **מגמה**: מה קרה למחירים בשכונה/בעיר ב-12 החודשים האחרונים, ותחזית קדימה (ריבית בנק ישראל, היצע, פרויקטים חדשים בנוריות).
- שקלל שזו דירה חדשה עם מסירה ~2028 (לא ניתנת למכירה/מאוכלסת מיד; יש מגבלות מכירה במחיר למשתכן — בדוק את תקופת ההגבלה).

## שלב 2 — מחקר שיפוץ
הבא **טווחי עלות 2026 בש"ח** עם מקור:
- **מטבח**: ספק קבלן מול מטבח חיצוני; טווח מחירים למטבח באורך ~4–6 מ' (כולל/לא כולל מוצרי חשמל ומשטח אבן/קוורץ).
- **שירותים**: עלות שיפוץ חדר רחצה אחד (ריצוף, אינסטלציה, כלים סניטריים) × מספר חדרי הרחצה בדירה.
- **הזזת/הריסת קיר**: ⚠️ קודם בדוק אם הקיר נושא או ממ"ד (אסור לגעת בקיר ממ"ד לפי חוק הג"א). עלות הריסה + בנייה מחדש + טיח/צבע + היתר אם נדרש.
- חלק לשלבים עם תקציב ריאלי לכל שלב + סה"כ.
- ציין מה כדאי לבקש מהקבלן עוד לפני המסירה (שינויי דיירים — לרוב זול יותר מלשנות אחרי).

## שלב 3 — עדכן את הקבצים
1. עדכן את שדה `valuation` ב-`apartment.json` (כולל `last_updated`, `sources`).
2. עדכן את הטבלאות ב-`README.md`: הערכת שווי + תוכנית שיפוץ.
3. הוסף שורה ל**אינדקס העדכונים** ב-`README.md`.
4. צור `updates/YYYY-MM-DD.md` עם snapshot מלא: מה נמצא, מקורות, ושינוי מהעדכון הקודם.
5. הרץ `python3 build_html.py` כדי לרענן את `index.html`.
