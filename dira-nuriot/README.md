## 🌐 פרסום ב-GitHub Pages

האתר מתפרסם מהענף `main` ומתיקיית השורש. קובץ `index.html` בשורש מפנה ללוח
שנמצא בתיקייה `dira-nuriot/`.

הגדרה חד-פעמית:

1. דוחפים את המאגר ל-GitHub כאשר `main` (או `master`) הוא ענף ברירת המחדל.
2. ב-GitHub פותחים **Settings → Pages → Build and deployment**, בוחרים
   **Deploy from a branch**, ואז `main` ו-`/(root)`.
3. כל push לענף `main` מפרסם את האתר. אפשר להריץ את
   **Actions → Refresh dashboard data** כדי לרענן את נתוני השוק.

ריצה מתוזמנת מרעננת את מקורות השוק ושומרת את לוח הנתונים המעודכן בכל יום שני.
קובץ ה-PDF הפרטי, קובצי state מקומיים, raw captures ו-snapshots אינם ב-Git.

## 🗂️ מבנה התיקייה

```
dira-nuriot/
├── index.html         ← אתר ניהול השיפוץ (פתח בדפדפן): תקציב, גאנט, שווי, דברים לביצוע
├── README.md          ← מסמך חי, מקור-אמת, סיכום + אינדקס
├── apartment.json     ← עובדות + שווי + מגבלות + דברים לביצוע (מקור-אמת)
├── renovation.json    ← תקציב שיפוץ (טווחי 2026) + לו"ז ביצוע (גאנט)
├── management.json    ← מודל שווי, השוואות, תזרים, מעקב שיפוץ וליקויים
├── PROMPT.md          ← הוראות מחקר לאייג'נט (מצב "אייג'נט")
├── update.sh          ← נקודת כניסה: data / agent / html
├── update_all.py      ← fetch → validation → snapshot → status → HTML
├── fetch_deals.py     ← מושך עסקאות מ-nadlan.gov.il (מצב "data")
├── build_html.py      ← מייצר את index.html מהנתונים
├── photo.jpg          ← (אופציונלי) תמונת הדירה — תוצג אוטומטית
├── assets/            ← (אופציונלי) assets/location-map.png — מפת מיקום סטטית לסקשן המסמכים
└── updates/           ← snapshot מתוארך לכל ריצה
```

**אינטראקטיבי:** ב-`index.html` אפשר לנהל מודל שווי שקוף, השוואות, תזרים, תקציב בפועל, ספקים וליקויי מסירה. העריכות נשמרות בדפדפן וניתן לייצא/לייבא גיבוי JSON מתוארך.

## ▶️ הפעלה

```bash
cd ~/Documents/dira-nuriot

./update.sh data     # מושך סיכום שוק ציבורי מ-Nadlan דרך GovMap ומרענן HTML
./update.sh agent    # מצב "אייג'נט": מדפיס את הפרומפט להזנה ל-Claude
./update.sh          # ברירת מחדל: data ואז מציע את מצב agent
python3 update_all.py # חלופה ניידת גם ללא bash
```

> 🪟 **Windows (PowerShell):** אין `bash` ולרוב אין `python3`. הרץ את הסקריפטים ישירות עם `python`:
> ```powershell
> python dira-nuriot\update_all.py    # צינור מלא: fetch → validate → snapshot → build
> python dira-nuriot\build_html.py    # בנייה מחדש של index.html בלבד
> python dira-nuriot\fetch_deals.py   # מצב data (משיכת נתוני שוק ציבוריים)
> ```
> מומלץ Python 3.11 (כמו ב-CI). את מצב "אייג'נט" מפעילים ע"י קריאת [`PROMPT.md`](./PROMPT.md).

> נתוני עסקאות בודדות באתר Nadlan מוגנים כיום ב-reCAPTCHA ובחתימת בקשה.
> מצב `data` משתמש רק בנקודות קצה ציבוריות שמתאימות להרצה אוטומטית: GovMap
> לזיהוי השכונה, אינדקס Nadlan למיפוי אזור סטטיסטי, ו-JSON הסיכום הרשמי.
> הפלט מתעד את גרסת הנתונים ואת פער השם/גבול בין נוריות לאזור הישן "מרום ראשון";
> הוא אינו מעדכן אוטומטית את הערכת השווי ב-`apartment.json`.

מקור משלים: דף שכונת נוריות ב-Madlan נסרק מתוך נתוני ה-SSR המובנים שלו ומספק
אינדיקציות עדכניות לפי מספר חדרים, מספר עסקאות ומחיר ממוצע למ"ר. הנתונים מתויגים
כמקור מסחרי ואינם מתערבבים עם עסקאות ממשלתיות. Yad2 אינו נסרק אוטומטית כרגע:
הגישה החיה מוגנת ב-anti-bot, וחבילת `yad2-scraper` 0.5.3 מתמקדת בעיקר ברכב ואינה
מספקת מודל תקין לדירות.

בנוסף נסרקת שכונת נרקיסים הסמוכה כבנצ׳מרק לשכונה חדשה. היא מוצגת כהשוואה
נפרדת בלבד, עם הפער מול נוריות, ולא נכללת אוטומטית בממוצע השווי של הדירה.
העדכון בודק גם את מיפוי Nadlan הממשלתי לנרקיסים. נכון ל-2026-06-20 הוא ממופה
לאזור הישן "צמרות" בגרסת 28-07-2025; קיימת אינדיקציית עסקאות אך שדות מחירי
השכונה ריקים, ולכן המקור מוצג כאזהרת איכות ואינו נכנס לחישוב.
